EKO Motorwear

EKO Motorwear is een website die ik ontwikkelde voor een motorzaak. Bezoekers kunnen informatie vinden over de aangeboden diensten, openingsuren en contactgegevens.

Gebruikte technologieën

  • HTML
  • CSS
  • JavaScript

Wat heb ik geleerd?

Tijdens dit project heb ik geleerd hoe ik een responsieve website kan bouwen en hoe ik een duidelijke navigatiestructuur ontwerp.
